# Telegram Summary Agent

Приложение собирает сообщения из Telegram и делает сводки с помощью ГосПромта.

## Если у вас уже есть архив с EXE

Распакуйте **всю папку** и запустите `TelegramSummaryAgent.exe`.
Python и PyCharm не нужны. Файл `.env` должен лежать рядом с EXE.

## Как собрать EXE из исходников

### 1. Подготовка

- Python 3.13 (64 bit) — на нём проверена сборка. Другие версии не проверялись.
- Скачайте проект из GitHub и распакуйте его.
- Откройте PowerShell в папке проекта. Можно использовать Terminal в PyCharm.

### 2. Установка библиотек — только в первый раз

Выполните команды по очереди:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 3. Сборка EXE

```powershell
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm TelegramSummaryAgent.spec
```

Готовое приложение появится в папке **`dist\TelegramSummaryAgent`**.

### 4. Запуск

1. Получите файл **`.env`** у автора приложения и положите рядом с EXE.
2. Запустите **`TelegramSummaryAgent.exe`**.
3. Войдите в свой Telegram и добавьте источники.

Для передачи приложения другому человеку отправляйте **всю папку** `dist\TelegramSummaryAgent`, включая `_internal` и согласованный `.env`.

## Архив с инструкцией

После сборки EXE выполните:

```powershell
.\.venv\Scripts\python.exe package_release.py
```

Рядом с EXE появится **«Как запустить.txt»**, а в `dist` — **`TelegramSummaryAgent.zip`**.
Чтобы включить в архив общие ключи из `.env` для передачи внутри компании, добавьте `--include-env` к этой команде. Личные сессии, базы и настройки не включаются.

## После изменения кода

Повторите команду из шага 3. Перед пересборкой полностью закройте приложение через значок в трее → **«Выйти полностью»**. После сборки снова положите `.env` рядом с EXE.

## Важно

- Свой файл **`.session` не передавайте** — это доступ к вашему Telegram. У каждого пользователя он создаётся при входе.
- EXE хранит сессию и настройки в `%LOCALAPPDATA%\TelegramSummaryAgent`.

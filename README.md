# Telegram Summary Agent

Приложение собирает сообщения из Telegram и делает сводки с помощью ГосПромта.

## Если у вас уже есть архив с EXE

Распакуйте **всю папку** и запустите `TelegramSummaryAgent.exe`.
Python и PyCharm не нужны. Файл `.env` должен лежать рядом с EXE.

## Как собрать EXE из исходников

### 1. Подготовка

- Python 3.13 (64 bit) — на нём проверена сборка. Другие версии не проверялись.
- Скачайте проект из GitHub и распакуйте его.
- Откройте PowerShell в папке проекта. Можно использовать Terminal в PyCharm.

### 2. Установка библиотек — только в первый раз

Выполните команды по очереди:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 3. Сборка EXE

```powershell
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm TelegramSummaryAgent.spec
```

Готовое приложение появится в папке **`dist\TelegramSummaryAgent`**.

### 4. Запуск

1. Получите файл **`.env`** у автора приложения и положите рядом с EXE.
2. Запустите **`TelegramSummaryAgent.exe`**.
3. Войдите в свой Telegram и добавьте источники.

## После изменения кода

Повторите команду из шага 3. Перед пересборкой полностью закройте приложение через значок в трее → **«Выйти полностью»**. После сборки снова положите `.env` рядом с EXE.

## Важно

- Сессия Telegram хранится в **Windows Credential Manager** текущего пользователя.
- EXE хранит базу источников и настройки в `%LOCALAPPDATA%\TelegramSummaryAgent`. Если записи сессии в хранилище Windows нет, приложение попросит войти в Telegram.

## Прокси Telegram

На экране входа или в «Настройки → Работа приложения» нажмите **«Прокси Telegram»**. Включите переключатель, вставьте ссылку `tg://proxy?...` или `https://t.me/proxy?...` и нажмите «Сохранить». Приложение проверит соединение с Telegram. После сохранения полностью выйдите и запустите приложение заново.

Поддерживаются обычные MTProxy, dd и ee (Fake TLS). Тип определяется по ссылке автоматически. Прокси работает для входа, чтения каналов, «Избранного» и отправки ботом. ГосПромт использует отдельное соединение. Настройки хранятся в `proxy_settings.json` рядом с остальными данными пользователя и не передаются вместе со сборкой.
